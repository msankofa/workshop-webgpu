Per-frame action order

  1. Sense: choose a live opposing target; cast eye-to-eye LOS; update last-known position and motion when visible.
  2. Maintain: update reload state and calculate whether ammo and cooldown permit a shot.
  3. Override: if muzzle recovery is active, continue reposition until the safe waypoint is reached.
  4. Choose: call chooseBotState using visibility, distance, aim error, memory, cooldown, committed-flee status, and the fully-out-of-ammo knife gate.
  5. Act: move a path, slew toward the target, or fire from the rendered weapon?s muzzle ray.

State selection rules

Condition, evaluated in orderChosen state
Health retreat is requested or committedFlee / Heal remains authoritative.
Knife secondary enabled; visible target inside knife-engagement range; primary magazine and reserve are both emptyKnife
Current state is flee and its route is still activeFlee remains authoritative.
Visible target is closer than flee distance (including exit buffer while fleeing)Flee
Visible target is farther than pursue distancePursue
Visible target at engagement distance, but aim error is highAim
Visible, aligned; weapon ready / cooling downFire / Aim
Target not visible; a last-known location existsSeek
Target not visible and no memory remainsPatrol

Reload is an action gate rather than a top-level state. The knife is not drawn for a normal reload; it is a last resort once both magazine and reserve are empty.

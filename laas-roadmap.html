LAAS v2 Fidelity Roadmap

Prioritized build order to close the gap between the current workshop-webgpu renderer and the PROJECT LAAS v2 spec. Ordered by fidelity-per-effort on top of the chassis we already have — not by the spec's phase order. Based on a three-agent codebase audit, 2026-07-04.

Where we stand

The codebase is a strong renderer chassis with almost none of the content and light-transport fidelity the six pillars demand. Overall ~1.5/10 against the spec — but the hardest-to-retrofit systems (streaming, GPU instancing, tested shader math) already exist.

PillarScoreState
A · Geometry, not textures2/10Vegetation is real geometry; ground is texture-splat on a 6-sine heightfield. No rock/cobble/litter meshes.
B · Light transport1/10One PCF shadow map + flat ambient. No GI, GTAO, bounce, or translucency. Shadows read gray.
C · Nothing is bare1.5/10No moss/vines/ferns/debris/dressing. A 2-band slope→material texture swap only.
D · Distance holds1/10Good LOD plumbing, no craggy content, flat billboard impostors, no volumetric clouds / far-detail synthesis.
E · Art direction1.5/10Good grade machinery but no ToD color script, auto-exposure, value structure, or composition system.
F · The world moves2.5/10Grass wind + lake water are real. Trees/plants static, no shared wind field, no streams, wrong particle species.

The chassis — build on this, don't rebuild it

  • CDLOD terrain streaming (cdlod-terrain.js) — GPU quadtree LOD + morphing, crack-free, indirect draws.
  • GPU-instanced vegetation (forest-gpu.js, grass-compute.js, plants-gpu.js) — deterministic seeded placement, 4-ring LOD, per-instance jitter.
  • Clustered forward+ lighting (clustered-lights.js) — 256 dynamic lights, real GGX. Direct only, no bounce.
  • Post/tonemap chain (post-fx.js) — AgX/ACES, full grade chain, bloom. Live-tunable, Node-tested, but unopinionated.
  • Lake water (water.js) — real reflection + refraction + caustics. Lakes only.
  • Grass wind + CPU/GPU math twins (forest-cull.js, light-cluster.js) — the one working vegetation motion; Node-testable shader math mirrors.
Tier 1Cheapest high-impact winsreuse existing machinery · days–weeks

Move E / B / F off the floor fast, and produce the review surface (composed shots, non-black shadows) needed to judge everything after.

T1.1 Time-of-day color script + auto-exposure + composition Pillar EBEffort S

  • Map sun elevation → per-ToD grade presets; enforce the teal-orange split automatically instead of via manual sliders.
  • Add EV-based auto-exposure, replacing the flat manual multiplier.
  • Add ≥9 camera bookmarks (1–9) + a ≥90s flythrough (C). No camera-path system exists today.

Turns an unopinionated instrument panel into a directed look. The cheapest 2-point jump on the board.

T1.2 Sky-driven ambient + no-black-shadows first slice Pillar BEffort S–M

  • Replace the flat AmbientLight constant with a hemispheric / SH sky-irradiance term (blue up, terrain-bounce tint down), driven by the sky palette.
  • Add a foliage translucency term (leaves transmit sun) — zero exists today.

Directly attacks "shadowed foliage reads gray." No probe volume yet — this is the cheap 80%.

T1.3 Wind on trees & plants via a shared gust field Pillar FEffort S–M

  • Author one shared global wind field (direction + gust-noise texture) sampled by all vegetation, not grass's private sine.
  • Wire hierarchical sway into trees.js (trunk→branch→leaf) and plants.js — both fully static today.

"Frozen frame one second from motion" — currently only true where grass is on screen.

Tier 2Medium builds on the instancing/compute engineweeks

T2.1 GTAO + screen-space contact shadows Pillar BEffort M

Implement the GTAO pass that post-fx.js stubs as "v2" (needs the MRT normal buffer, already the flagged prerequisite). Add short-raymarch contact shadows so every pebble and grass clump is grounded.

T2.2 Ground dressing + near-field debris Pillar CAEffort M–L

  • Scatter cobbles/pebbles (3+ size classes, water-rounded near streams), twigs, leaf-litter cards, bark chips — floor is ≥80k near-field instances; today it's 0.
  • Per-surface dressing: cliff moss/vines/ledge ferns/dirt streaks; tree-base root flare/litter/fungi; stream-margin wet darkening.
  • Per-instance hue/value/age jitter + a dry/broken/dead fraction (tree-age.js exists but is unwired).

Kills "bare terrain texture within 10m" — the single biggest Pillar A/C failure. Depends on nothing; run it parallel to Tier 1.

T2.3 CSM cascades + PCSS Pillar BEffort M

Upgrade the single fixed-frustum 2048² shadow map to 4 texel-snapped CSM cascades + PCSS contact hardening.

Tier 3Large builds, high fidelity ceilingweeks–months each

T3.1 Simulated + eroded heightfield with rivers Pillar ADEffort L

GPU hydraulic (pipe-model) + thermal erosion ≥500 iters on a ≥4096² grid; flow-accumulation → river network → channel carve → moisture field. Replaces the analytic terrainHeightAt. The geology foundation everything sits on.

Unblocks T3.2 and improves T2.2 placement. Start of the Tier-3 dependency chain.

T3.2 Rock/cliff geometry + far-detail synthesis + cobbled streambeds Pillar ADEffort L

  • Hero rock/cliff generator (≥200k tris LOD0, ≥6 displacement octaves, craggy silhouettes).
  • In-shader distance re-amplification so 10km peaks stay serrated (ridged detail in normal/height domain).
  • Fully-cobbled streambed geometry (needs T3.1 rivers + T2.2 debris).

T3.3 Hillaire atmosphere + volumetric clouds + cloud shadows Pillar DBEEffort L

  • Hillaire-style transmittance + multi-scatter LUTs driving sky, aerial perspective, and IBL (replaces the gradient dome + flat THREE.Fog).
  • Raymarched Worley–Perlin 2-layer clouds w/ temporal reprojection, sitting below peaks; cloud shadows on terrain. Today: one unlit 2D noise plane.

Independent of the terrain rebuild — can run parallel to T3.1/T3.2.

T3.4 Irradiance probe volume GI + screen-space bounce Pillar BEffort L

Per-chunk irradiance probe volume (≥24×24×6), async GPU-updated from sky+sun+terrain bounce; + screen-space color bleed. Completes T1.2 into the full no-black-shadows law.

Tier 4Throughput to actually hit the floorsafter content exists

T4.1 Meshlet/Hi-Z culling + octahedral impostors + triangle HUD FloorsEffort L

  • ~64-tri cluster culling with frustum + Hi-Z occlusion → compacted indirect draws (occlusion is absent today; per-instance frustum cull was deliberately dropped).
  • Octahedral impostors (≥8×8 views, albedo+normal+depth) replacing the single flat billboard.
  • HUD triangle counter to verify the ≥5M forest / ≥3M vista floors.

Last on purpose — meaningless until Tier 3 produces enough geometry to need culling.

Sequencing: Do Tier 1 first regardless (cheap, and its bookmarks + ambient give you the review surface). T2.2 depends on nothing — run it parallel. Tier 3 is a chain: T3.1 unblocks T3.2; T3.3 and T3.4 run parallel. T4.1 is last. Keep the CPU/GPU math twins in sync for any new TSL math.

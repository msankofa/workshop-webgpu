Height composer (classic)

v4's continentalness × erosion × weirdness composer. It feeds the stack below as the classic layer.

Layer stack

Ordered layers folded top to bottom into the pre-erosion height. Sources add noise, imports or constants with a blend mode, opacity and an optional height-band mask; modifiers warp the coordinates or terrace the running height.

Erosion & hydrology

Derived masks

Biome classification

17 ordered rules run top to bottom over every cell; whichever one matches last wins. Painted biomes show as rule −2.

Material masks

Blended surface material from biome id, slope, and height.

Paint

Turn on Paint in viewport, then drag on the 3D ground. Height paint is a delta added after erosion; biome paint overrides the classifier per cell. A whole stroke is one undo step.

Import heightmap

A grayscale image or a real-world patch becomes an import layer in the stack, so it blends and masks like any other source.
